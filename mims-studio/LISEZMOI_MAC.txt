mi-gen Studio — version navigateur (aucune installation)
=========================================================

Double-clique sur MIMS_Studio.html : il s'ouvre dans Safari (ou Chrome).
Tout tourne en local dans la page, aucune connexion requise.

Prise en main rapide :
  - onglet Construire : modèles prêts à jouer, formes 3D, import .obj/.stl
  - bouton "Son" puis barre espace = frapper
  - clic sur un point de la vue 3D = inspecteur (frapper, pincer, écouter...)
  - onglet Réglages = tous les paramètres en curseurs
  - onglet Export Max = fichier .gendsp pour [gen~]

Si Safari affiche le code au lieu de l'application : le fichier a
peut-être été renommé en .txt pendant le transfert — remets
l'extension .html et rouvre-le.
