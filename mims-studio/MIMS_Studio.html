Utiliser dans Max
  1. Installe le package mi-gen dans le dossier Packages de Max (github.com/mi-creative/mi-gen) : il fournit migen-lib, migen-integrated et migen-proxies.
  2. Range le .gendsp à côté de ton patch, puis crée un objet [gen~ @gen nom] (nom du fichier sans extension) relié à un [dac~].
  3. Entrées in1… : position (posInput), force (frcInput) ou audioParam, dans l'ordre affiché ci-dessus. Sorties out1… = tes sorties ; la dernière donne le nombre de masses (pour l'affichage).

mi-gen Studio — prise en main

CONSTRUIRE
  Choisis un modèle prêt à jouer, une forme 3D, ou importe un .obj / .stl.
  Ajoute des cordes, membranes, oscillateurs... (structures intégrées mi-gen).
  Clique un point dans la vue : l'inspecteur propose Frapper, Pincer,
  Frotter, Coup de force, Écouter, Supprimer. Maj+clic sur un 2e point :
  Relier. Sur une corde ou une membrane, le point devient un proxy dont
  la position se règle ensuite avec un curseur.

JOUER
  🔈 Son : son temps réel (1 pas de calcul = 1 échantillon, comme gen~).
  ⚡ Frapper ou barre espace : coup sur les entrées de force, sinon
     impulsion sur le point sélectionné (ou le plus haut).
  Bille jaune : attrape-la et glisse verticalement (frapper, pincer...).
  Réglages : tous les @param en curseurs, actifs pendant le jeu.
  ▶ Animer : simulation visuelle sans son (curseur vitesse).

VUE 3D
  glisser : orbiter      molette : zoom      clic droit : déplacer
  double-clic : recadrer clic : sélectionner Maj+clic : 2e point

BUDGET
  La jauge en bas indique la charge du son sur un coeur de ta machine
  (mesurée au démarrage). Au-delà de 100 % le son décroche : l'import 3D
  vise automatiquement ~50 %.

MAX
  Onglet Export Max : .gendsp prêt pour [gen~], ou .mdl pour MIMS4Max.
  Les fichiers .mdl de mi-gen s'ouvrent ici tels quels.
