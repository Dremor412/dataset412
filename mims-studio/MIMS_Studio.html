MIMS Studio — aide

SOURIS (vue 3D)
  glisser gauche : orbiter
  molette / trackpad : zoom
  glisser droit (ou deux doigts) : deplacer
  double-clic : recadrer
  clic simple : selectionner une bille

SIMULATION
  Simuler : lance la physique (les billes bougent en hauteur)
  Frapper (ou barre espace) : impulsion sur la bille selectionnee
            (ou la plus haute) ; curseur force = intensite
  bille jaune (posInput) : l'attraper et la glisser verticalement
            pour appuyer, pincer ou frotter l'objet
  vitesse : nombre de pas de calcul par image (sans le son)
  amplification : exagere visuellement le mouvement

SON
  Son : ecoute en temps reel (1 pas de calcul = 1 echantillon,
        comme gen~). Les posOutput sortent a gauche / droite ;
        sans posOutput on ecoute deux masses de l'objet.
  volume : gain avant le limiteur doux (en dB)
  Le son est souvent trop rapide pour l'oeil : monte l'amplification.

COULEURS
  bleu = masse mobile   rouge = point fixe (ground)
  jaune = posInput      cercle vert = sortie ecoutee
  orange pointille = contact   violet = archet   vert = pluck
